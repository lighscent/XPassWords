# XPassWords

Vous pouvez également télécharger l'extension depuis le Chrome Web Store : [XPassWords](https://chromewebstore.google.com/detail/xpasswords/aeghbmkkeikcdanooblnneibjndggoah?authuser=0&hl=fr)

## Description

XPassWords est une extension de navigateur Google Chrome qui permet de génerer des mots de passe.
Elle est conçue pour être simple et rapide à utiliser, tout en offrant une sécurité maximale. L'extension utilise des algorithmes de génération de mots de passe robustes pour garantir que les mots de passe générés sont uniques et difficiles à deviner.

## Fonctionnalités

- Génération de mots de passe aléatoires
- Personnalisation de la longueur du mot de passe
- Options de complexité (majuscules, minuscules, chiffres, caractères spéciaux)

## Installation

1. Téléchargez le code source de l'extension.
2. Ouvrez Google Chrome et accédez à `chrome://extensions/`.
3. Activez le mode développeur en haut à droite de la page.
4. Cliquez sur "Charger l'extension non empaquetée".
5. Sélectionnez le dossier contenant le code source de l'extension.
6. L'extension devrait maintenant apparaître dans votre liste d'extensions.
7. Cliquez sur l'icône de l'extension pour l'ouvrir.
